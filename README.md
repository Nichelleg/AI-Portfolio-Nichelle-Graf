### NewsBot Intelligence System
*ITAI 2373 — NLP Midterm & Final Project*

A production-ready news categorization and querying platform built end-to-end across two project phases. The midterm delivered a multi-pipeline NLP system using TF-IDF and topic modeling (LDA/NMF) for automated news classification. The final project (NewsBot 2.0) extended it with transformer-based embeddings, named entity recognition, and a conversational AI interface for live news querying.
